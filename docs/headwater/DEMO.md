# Two-minute demonstration

## Before judging

Run locally with source data cached. Configure Bedrock and verify an actual Nova 2 Lite tool-using investigation before claiming a live model demonstration. Configure an eligible Photon SIP line and ElevenLabs agent only if demonstrating that integration. No phone call has been verified during this build.

Use a fresh exercise workspace, the full November 14 evidence cutoff and 10 m assumed stage. Press P for presentation layout. The guided demo uses N to advance. Keep a clearly labelled recording as a presentation fallback.

## Script

**0–15 seconds:** “A disaster map can show where an impact happened. A response team also needs to know who needs help, which resources fit, and whether the mapped access has changed. Headwater connects these decisions to inspectable evidence.”

**15–35 seconds:** Orbit the real 3D Rasuwa terrain and select a request. “We use real Copernicus assessment points, terrain and mapped roads. These people, requests and teams are exercise records.” Change stage from 10 to 20 m: higher-band assessed assets change from 54 to 101. “This is an assumption-sensitive exposure screen, not a flood prediction.”

**35–70 seconds:** Review a resource proposal and its mapped route. Assign the exercise team, verify the access-review gate, then inject the road closure. Show the affected mission flagged for review. “A changed access constraint invalidates the previous plan. A line on the map is not a promise that a road is passable.”

**70–90 seconds:** Open Contact desk and record an exercise participant requesting transport. “Contact acknowledgement and rescue completion are different states.” Show the configured test-call flow only if it has actually been tested; otherwise describe the adapter as pending configuration.

**90–110 seconds:** Ask the agent: “Review the current assistance requests and access constraints. What must an operator verify?” Show actual tool events. Identify the mode explicitly: live Bedrock/deepagents if verified, otherwise local reproducible workflow without a model call.

**110–120 seconds:** Export the assessment and operations log. “Every proposal leaves an audit trail: sources, assumptions, access uncertainty and operator actions.”

## Questions

- **Does this predict failure time or a safe route?** No. It screens explicit scenarios, maps candidate access and tracks review requirements.
- **Is this a complete population inventory?** No. The 433 building points and five crossings are a selected post-event assessment sample.
- **Does 10 m mean water depth at a house?** No. It is an assumed channel stage in a relative-terrain screen.
- **What does the AI do?** It selects evidence, exposure and response tools and explains their computed outputs. It cannot dispatch teams or place calls.
- **What is implemented for calling?** Exercise scripts/outcomes and a configurable approved, allowlisted Photon SIP / ElevenLabs test-call adapter. Automatic verified transcript intake is not implemented.
- **What is new?** The demonstration tests one connected evidence-to-response workflow. Do not claim a world-first or operational validation.
