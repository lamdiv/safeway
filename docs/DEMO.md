# SafeWay — two-minute judging script

Before presenting: open operator plus Phone A and Phone B in separate profiles. Enroll both with explicit exercise-location consent. Start and pause. Keep sponsor claims tied to verified evidence; the Houston drill geometry is synthetic.

**0–15 s:** “Evacuation guidance goes stale when an approach closes. SafeWay removes old directions first, then waits for the exact evidence needed to issue a replacement.” Show the monitoring page: actual source timestamps, official alerts and provisional gauge height; unknown site-specific hazard stays unknown.

**15–35 s:** Operator + phones. Phone A receives the preapproved west approach; Phone B is outside the warning boundary. “Each resident has a separate session and current guidance revision.”

**35–60 s:** Next event: west approach closes and staged flood expands. Show the old route disappear from Phone A. “The alternate is withheld: east entrance is not explicitly open, and the indoor connection is not verified.”

**60–80 s:** Next event verifies the staged interior link; directions stay withheld. Next event supplies the current staff door-open observation. The approved east approach appears automatically. “A scan can support a connection; only a current observation tells us a door is open.”

**80–105 s:** Phone A acknowledges and self-reports check-in. Phone B sends SOS; operator acknowledges. Show that receipt, acknowledgement, check-in and safe report are distinct states. Stop Sharing on Phone A and show location removed.

**105–120 s:** End exercise: both phones show ended; active/SOS locations clear and future uploads are rejected. Export de-identified decisions. “The model can explain evidence, but code decides eligibility.”
