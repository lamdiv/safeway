# Headwater response interface

References inspected November 14, 2026:

- https://godseyeview.ai/ — inspected screenshot: black/cyan intelligence aesthetic, monospaced telemetry and sparse outlined controls. This capture is the official landing page, not proof of the application’s complete UI.
- https://github.com/bilawalsidhu/gods-eye-view — map-first interaction and explicit source/simulation states.
- https://firesight-dashboard.onrender.com/ — inspected running field-operations view: map occupies the screen; floating panels contain personal hazard/status information. Cream/green colors are observed there, not used as Headwater’s palette.
- https://devpost.com/software/tim-oje76l and https://github.com/lily1c/la-hacks-2026 — the LA Hacks FireSight reference. Distinct from the unrelated VR project with the same name.

The Headwater implementation is an original synthesis: dark blue terrain/imagery, cyan primary action, amber household paths, blue flood screen and green response resources. One right-side panel has People / Response / Activity tabs; a bottom scrubber controls exercise motion. Evidence and technical detail are in a separate research view. These tokens and layouts are proposed choices, not exact extracted measurements.

Playback represents hypothetical people and timing on real cached geography. The warning review states the exact drill assembly coordinates and mapped access. Actual provider acceptance, participant acknowledgement and arrival remain distinct states. Assembly Point A is an exercise point, not an approved real shelter.
